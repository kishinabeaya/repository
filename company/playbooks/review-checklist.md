# 手順書: レビューチェックリスト（analyst）

判定: **PASS**（そのまま可）/ **FIX**（軽微な修正で可）/ **REJECT**（作り直し）

## 1. 目的・完了条件
- [ ] タスクの完了条件をすべて満たしているか
- [ ] OKRへの貢献が明確か

## 2. 事実・数字
- [ ] 主要な事実・数字に出典があるか（いくつか実際に確認する）
- [ ] 推測と事実が区別されているか

## 3. 品質
- [ ] ターゲット顧客にとって価値があり、価格に見合うか
- [ ] 誤字脱字・論理の破綻・リンク切れがないか

## 4. 法令・規約（外部に出るもの＝L2は必須）
- [ ] 誇大表現・断定表現がないか（景品表示法）
- [ ] 実在しない体験談・レビューがないか
- [ ] 広告であることを隠していないか（ステマ規制）
- [ ] 他者の著作物・商標・肖像を無断で使っていないか
- [ ] 医療・金融・法律など、資格や特別な規制がある領域に触れていないか
- [ ] 販売する場合、特定商取引法に基づく表記の要否が確認されているか
- [ ] 掲載先プラットフォームの規約に反していないか

## 5. 制約
- [ ] 追加費用が発生しないか（D-0002）
- [ ] 公開・送信をしていないか（D-0003）

- 重大な指摘:
- 軽微な指摘:
- 修正案:
