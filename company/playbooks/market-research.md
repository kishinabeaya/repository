# 手順書: 市場調査・商品候補の選定（strategist）

## 評価軸（各5点満点、合計で比較）
| 軸 | 見るポイント |
|---|---|
| 市場の成長性（D-0005） | 市場規模が拡大しているか。調査会社・業界団体・公的統計など出典のある推移データで判断する |
| 陳腐化しにくさ（D-0005） | 技術の進化や流行の終わりで価値が消えないか。1年後も売れ続けるか |
| 収益化までの速さ | 制作から販売開始まで何日か。7日以内が理想 |
| 初期費用ゼロ | 無料で出品・販売できるか（D-0002） |
| 需要の証拠 | 類似商品の販売数・レビュー数・ランキング・検索需要など、確認できる事実 |
| AIでの制作しやすさ | AI社員だけで品質の高いものを作れるか |
| CEOの作業時間 | 出品・対応などCEOの手作業が少ないか |
| 法的・規約上のリスク | 著作権・規約・資格が必要な領域（医療・金融・法律）でないか |

## 手順
1. 候補を5〜10案出す（デジタル商品を中心に、販売チャネルとセットで考える）。
2. 各候補の需要の証拠を、販売プラットフォームや検索結果から確認する（出典URLを記録）。
3. 評価軸で採点し、比較表にする。
4. 推奨1案＋代替案2案を選び、次を書く:
   - ターゲット顧客（誰の、どんな悩みか）
   - 商品の概要と、競合との違い
   - 想定価格帯と根拠（類似商品の価格）
   - 販売チャネル
   - 最初の1件を売るまでの道筋（日数）
5. 選ばなかった案と理由も残す（後で再検討するため）。

## 注意
- 「よく売れているらしい」は根拠にならない。確認できた事実だけを根拠にする。
- 調べきれなかった点は「未検証」として明記する。
