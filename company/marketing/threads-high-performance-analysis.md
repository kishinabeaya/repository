# 0. 先に読む（結論と限界）

- **結論:** 反応の最大の裏付けは「返信（会話）」。Metaは2026年7月の日本向け説明で、Threadsのインプレッションの50%超を返信が占め、日本ではこの傾向がより強いと説明した（出典M1）。却下された投稿案は「読んで終わる一方通行」で、返信のきっかけと冒頭の引きがなかった。
- **限界（重要）:**
  1. 完了条件の「反応の高い投稿20件以上」は**未達**。本文と数値の両方が確認できた実例は、検索では1件も取れなかった。数値だけ取れた事例が約7件。Threadsの投稿は検索に載りにくく、threads.net/threads.comは直接見られない（検索30回の枠で、Web検索のみ）。
  2. dev.to・teract.ai・socialmediatoday.comなどのページ本文は、このセッションからは取得できなかった（ネットワーク制限）。数値は**検索結果の要約**に基づき、原文未確認。
  3. 英語圏の民間ツール会社・ブログの分析が中心で、利害があり、手法は不明。日本語圏の定量分析（冒頭の1行・文字数・投稿時間）は**見つからなかった（不明）**。
  4. 占い・星座ジャンルでThreadsの実績が数字で出ている事例は**見つからなかった**。
- **対応案:** 不足分は、CEOの実績データ（9章）と、CEOがThreadsの検索・おすすめ画面で見つけた高反応投稿のスクリーンショット（10〜15件、約15分）で補うのが最も確実。

信頼度の表記: 【事実】出典に数値・発言がある（ただし二次情報）／【推測】根拠が一般論・単一の逸話／【不明】データなし。

**避けること（規約・信頼）**
- 「いいねしたら〜」「RTして」など露骨な反応稼ぎ。Metaはエンゲージメントベイトを抑制する方針をFacebookで公表している（Threadsでの扱いは**未検証**）。問いかけは「自分の話を書いてもらう」形にとどめる。
- 炎上狙いの投稿（レイジベイト）は、短期の反応はあるが会話が続かない（W1）。ブランドと占い・自己理解の信頼にも合わない。
- 運勢を煽る・断定する表現（CLAUDE.md・却下案の禁止表現リストに準拠）。

# 3. 投稿の「型」（5種類）

共通ルール: 1行目で「誰の・何の話か」が分かる／絵文字は多用しない／最後に返信しやすい一言／免責は1行に短縮（長いと冒頭より目立つため）。例文は**型の説明用のイラスト**で、投稿案ではない（T-0004で作り直す）。

## 型1「星座を選んで返信」型（既存の星座形式を活かす）
- 構成: ①1行目に引き（今日の一言のお題）→ ②3〜4星座だけ（またはタイプ別）→ ③「あなたの星座は？ 当たった・違ったを一言どうぞ」
- 根拠: F1・F3。CEOの実績で星座別の運勢にインプレッションが集まった（D-0007）ので、形式は残し、**12星座一覧の羅列は返信に結びつきにくい**点を直す（推測）。
- 例（自己理解）:
  ```
  「頑張りすぎた日の夜」にやりがちなこと、星座で分けてみた。
  牡羊座｜まだ何かやろうとする
  蟹座｜誰かの連絡を気にして寝落ち
  山羊座｜明日の段取りを頭で回す
  あなたはどれ？ 他の星座の人はどうしてる？
  ```
  （3星座に絞り、残りは次の投稿に回す）

## 型2「共感の一行＋具体例＋問い」型
- 構成: ①誰もが「あるある」と思う1行 → ②具体的な場面を1〜2行 → ③自由回答の問い
- 根拠: F1・F3・F4。M1（日本ではテキスト会話の場）。
- 例:
  ```
  「大丈夫？」って聞かれると、反射で「大丈夫」って答えちゃう人。
  本当は少し疲れてるのに、説明するのが面倒で。
  みんな、そんなとき何て返してる？
  ```

## 型3「意外な一言→理由」型
- 構成: ①少し意外な主張を1行（断定しすぎない）→ ②その理由を2〜3行 → ③「どう思う？」で終える
- 根拠: F5（W1。意外な主張＋理由は会話が続く。数値なし）。
- 例（自己理解）:
  ```
  自己分析って、増やすほど迷うことがある。
  タイプや星座を知るほど「自分はこうだから」で選択肢が狭まるから。
  私は「当たってるところだけ使う」くらいがちょうどいいと思う。
  あなたは診断や占いをどう使ってる？
  ```
  注意: 占いを否定しすぎない。自分の商品の立場とずれない範囲で（CEO判断）。

## 型4「ミニストーリー（2〜3文＋ひねり）」型
- 構成: ①きっかけ → ②小さな出来事 → ③意外な気づき → ④（任意）問い
- 根拠: F5（W1。一貫して伸びる形式とされるが数値なし）。
- 注意: 体験談は**CEO本人の実体験のみ**。作り話の体験談を投稿するのはステルス・誤認の恐れがあるため禁止。CEOの実体験が出せない場合は、型4は使わない。
- 例（構成のみ）: 「友達に誕生日から『性格当てて』と言われた→数字を足しただけで盛り上がった→当たるかより『自分の話を聞いてもらえた』感じが嬉しかった」

## 型5「二択・選んで返信」型
- 構成: ①お題1行 → ②A／Bの二択（各1行）→ ③「どっち？ 理由も一言」
- 根拠: F1・F3（返信のハードルが低い）。Threadsにはアンケート機能がある（Starbucks Japanもアンケート・クイズを使用／S1）。
- 例:
  ```
  休日の朝、先に整えるのはどっち？
  A 部屋（机の上だけでも）
  B 自分（コーヒーとぼんやり）
  数秘や星座の話はまたあとで。まず直感で。
  ```

**型の使い分け（案）**: 週の主力は型2・型5（返信を得やすい）、型1は星座形式の継続、型3・4は週1本。効果は9章の実績データと公開後の計測で比べる。

| W5 | **内容が一般的なアドバイス**（「机を5分片づけ」等）で、感情の引っかかりがない。全星座が同じ穏やかなトーン | 型2のように具体的な場面と「あるある」が必要（F1・F5） |
