# 経営上の制約（CoS・全社員が必ず守る）

| 項目 | 制約 | 根拠 |
|---|---|---|
| 予算 | 初期の支出は0円（Claude Proプランの利用料のみ）。**売上が出た後は、収益の再投資が可（案ごとにCEO承認・L2）** | D-0002、D-0017 |
| 外部公開 | すべてCEO承認制 | D-0003 |
| 事業領域 | 指定なし。ゲームに限らない。最速の収益化を最優先。小さく複数試す | D-0001、D-0017 |
| 商品形態 | CEOが対応する商品（鑑定・ライブ配信）も可。最速の収益化を最優先 | D-0006 |
| SNS | 占い・自己理解用のThreadsアカウント（投稿はCEO承認制）。MBTI系アカウントは**リポスト可（D-0019）**、宣伝の投稿は不可。運営者の同一性が見る人にわかるようにする（推奨） | D-0005, D-0006, D-0019 |
| 提供原則 | 5項目（隠さない／客観効果を約束しない／不安をあおらない／続ける理由を価値に／価格を弱さに連動させない） | D-0015、service-principles.md |
| 組織 | CoS＋5名（strategist, builder, creator, marketer, analyst） | D-0004 |
| AI使用量 | Proプランの利用上限内。社員の呼び出しは1回の /daily で最大3回 | D-0002 |

## 予算ゼロで使える前提のもの
- 無料で出品できる販売プラットフォーム（販売時の手数料のみ発生するもの）
- 無料のSNSアカウント、無料ブログ・ノート系サービス
- GitHub（無料プラン）

## 人間（CEO）にしかできないこと
- アカウント開設・本人確認・銀行口座や決済の設定
- 実際の出品・投稿ボタンの操作（当面）
- 法的な表示（特定商取引法に基づく表記など）の最終確認
