# 経営上の制約（CoS・全社員が必ず守る）

| 項目 | 制約 | 根拠 |
|---|---|---|
| 予算 | Claude Proプランの利用料のみ。それ以外の支出は0円 | D-0002 |
| 外部公開 | すべてCEO承認制 | D-0003 |
| 事業領域 | 指定なし。最速の収益化を最優先 | D-0001 |
| 商品形態 | CEOが対応する商品（鑑定・ライブ配信）も可。最速の収益化を最優先 | D-0006 |
| SNS | 占い・自己理解用のThreadsアカウント（投稿はCEO承認制）。MBTI系アカウントはリポスト・フォローのみ | D-0005, D-0006 |
| 組織 | CoS＋5名（strategist, builder, creator, marketer, analyst） | D-0004 |
| AI使用量 | Proプランの利用上限内。社員の呼び出しは1回の /daily で最大3回 | D-0002 |

## 予算ゼロで使える前提のもの
- 無料で出品できる販売プラットフォーム（販売時の手数料のみ発生するもの）
- 無料のSNSアカウント、無料ブログ・ノート系サービス
- GitHub（無料プラン）

## 人間（CEO）にしかできないこと
- アカウント開設・本人確認・銀行口座や決済の設定
- 実際の出品・投稿ボタンの操作（当面）
- 法的な表示（特定商取引法に基づく表記など）の最終確認
